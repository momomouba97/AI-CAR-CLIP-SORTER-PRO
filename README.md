# YouTube Downloader Studio — نسخة macOS (Intel / Big Sur 11.7)

أداة تستورد فيديوهات قناة YouTube، تحدّد ما تريد، وتحمّله حتى 1080p بصيغة MP4 ثم ZIP.
بدون cookies، بدون تسجيل دخول، بدون API. استخدمها فقط مع محتوى تملك حق تنزيله.

## الطريقة 1 — بناء التطبيق على GitHub
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه **كل محتويات هذا المجلد** (بما فيه المجلد المخفي `.github`).
2. افتح تبويب **Actions** ثم **Build macOS app** ثم **Run workflow**.
3. بعد نحو 10–15 دقيقة افتح التشغيلة الناجحة ونزّل **YouTubeStudio-mac-intel** من قسم Artifacts.
4. فك الضغط، وانقر مرتين على **Start YouTube Studio.command**.
   - إن منعه macOS: كليك يمين ▸ فتح ▸ فتح. أو في الطرفية: `xattr -cr` على المجلد.
5. تفتح الواجهة في المتصفح. الملفات تُحفظ في `~/yt_studio`.

## الطريقة 2 — بدون GitHub
ثبّت Python 3.10+ من python.org، ثم في الطرفية داخل هذا المجلد:
```
bash run.command
```

## ملاحظات
- نسخة yt-dlp داخل التطبيق ثابتة وقت البناء. إذا توقف التحميل مستقبلاً بسبب تغيّر YouTube، أعد تشغيل Workflow لبناء نسخة بأحدث إصدار.
- حجبُ YouTube قد يحدث أحياناً حتى من الشبكات المنزلية. ابدأ بفيديو أو اثنين، وأبقِ التوازي بين 3 و5.
- `cookies.txt` اختياري تماماً ولا يلزم إلا إن ظهر طلب تسجيل الدخول.
