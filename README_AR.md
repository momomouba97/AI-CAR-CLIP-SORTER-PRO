# AI CAR CLIP SORTER PRO — Mac Intel

## الإصدار المحسّن
واجهة macOS مستقلة مبنية باستخدام Tkinter، مع تصميم داكن أكثر تنظيماً ومركز عمليات ظاهر داخل التطبيق.

## المزايا
- تقسيم الفيديو إلى مشاهد باستخدام PySceneDetect (Content Detector وAdaptive Detector).
- التحكم في حساسية الكشف وأقصر مدة للمشهد.
- اختيار مجلد مستقل لحفظ المقاطع الناتجة؛ يتم حفظ هذا الاختيار تلقائياً وإعادة استخدامه عند تشغيل التطبيق لاحقاً.
- شريط تقدم للتصدير يوضح النسبة وعدد المقاطع التي تم إنجازها.
- أثناء تحليل المشاهد يظهر شريط متحرك لأن PySceneDetect لا يوفر في هذا التنفيذ نسبة تقدم دقيقة للتحليل.
- سجل عمليات يوضح مراحل التحليل، وعدد المشاهد، وكل مقطع تم تصديره، والأخطاء عند حدوثها.
- مشغل تلقائي Loop لمراجعة المقاطع من مجلد الحفظ المحدد.
- تصنيف MovingCars / StoppingCars / ExcludedCars.
- تجاوز مؤقت، إعادة المقاطع المتجاوزة، والتراجع عن آخر تصنيف.
- إحصائيات للمقاطع والمجلدات.
- حفظ إعداد مجلد الحفظ وحالة الفرز محلياً في Application Support.

## أماكن الملفات
- مجلد المقاطع المصدرية: المكان الذي تختاره من زر **اختيار مجلد الحفظ**.
- مجلدات التصنيف: افتراضياً داخل `~/Movies/AI CAR CLIP SORTER/`، ويمكن تغييرها من زر **تغيير مجلد العمل**.
- إعدادات التطبيق وحالة التراجع: `~/Library/Application Support/AICarClipSorter/`.

## البناء المجاني عبر GitHub Actions
1. ارفع `main.py` و`README_AR.md` المحدّثين إلى المستودع، مع الإبقاء على `requirements.txt` و`.github/workflows/build.yml` الحاليين.
2. افتح Actions ثم Build Mac Intel App ثم Run workflow.
3. بعد نجاح البناء، حمّل Artifact باسم `AI-CAR-CLIP-SORTER-PRO-MAC-INTEL`.
4. فك ملف ZIP وانقل التطبيق الجديد إلى Applications، واستبدل النسخة القديمة بعد إغلاقها.

## ملاحظات الاختبار
- تم فحص صياغة Python (`py_compile`) في بيئة البناء هنا.
- لم يتم تشغيل واجهة Tkinter على جهاز Mac الحقيقي في هذه البيئة؛ اختبر النسخة الجديدة على جهازك قبل اعتمادها نهائياً.
- أثناء تحليل المشاهد لا تعرض المكتبة المستخدمة نسبة مئوية دقيقة؛ لذلك يظهر شريط متحرك مع سجل يوضح مراحل التحليل. أما التصدير فيعرض نسبة تقدم فعلية حسب عدد المقاطع المكتملة.
- معاينة الفيديو في هذه النسخة لا تتضمن صوتاً.
- قد يعرض macOS تحذيراً لأن التطبيق غير موقّع بشهادة Apple Developer.
